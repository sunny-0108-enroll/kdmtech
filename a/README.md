## GitHub Pages 올리는 법
1. 이 폴더의 **모든 파일**(숨김 파일 `.nojekyll` 포함)을 저장소 맨 위(root)에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 확인합니다.
